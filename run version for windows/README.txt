Windows Run Version

This folder contains the ready-to-run Windows version of the program.

How to run:
1. Download circulation_sim.exe.
2. Double-click it, or open Command Prompt in this folder and run:
   circulation_sim.exe

The executable is built from the same C++ source code in the main repository.

If Windows SmartScreen appears because the file is downloaded from GitHub, use the normal Windows review prompt and only run it if you trust this repository/source.

The program opens in the terminal and includes the graph menu, BFS, DFS, Dijkstra, blood-cell profiling, and Graphviz DOT export.
